# Leaf & Latte — One-page Café Website

A responsive café landing page built with plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP file.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Responsive navigation with mobile menu
- Hero section and café location card
- Breakfast cards
- Why choose us feature section
- Featured menu carousel with controls and dots
- Promotional cards
- Newsletter form demo
- Reservation form demo
- Responsive footer

## Important
The forms currently show front-end demo messages only. They do not send emails or save information. To accept real reservations and newsletter signups, connect a PHP/MySQL backend.

Food photography is loaded from Unsplash URLs, so an internet connection is needed for those images and Google Fonts.
